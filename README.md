# 杨卓橦 · Agent 智能问答体知识库

本仓库是**简历链接背后的 AI 问答 Agent** 的知识库素材。面试官扫描简历上的链接后，Agent 可基于本仓库内容，用候选人的第一人称口吻回答关于简历的疑问。

## 目录结构

| 文件 | 格式 | 用途 |
|------|------|------|
| `杨卓橦-简历 2026秋招.md` | Markdown | 中文简历（纯文本，保留层级结构） |
| `Zhuotong Yang Resume 2026.md` | Markdown | 英文简历（纯文本，保留层级结构） |
| `Agent基础库 Q&A.md` | Markdown | 面试官可能提问的 **33 组问答**（人类可读） |
| `Agent基础库 Q&A.json` | JSON | 同上问答的**结构化版本**（机器/Agent 检索友好） |

> 原始文件（PDF / DOCX）无法被 GitHub 直接读取，故转换为上述文本格式。如需视觉版简历，请保留原 PDF。

## 如何使用

- **人类审阅**：直接查看 `.md` 文件，GitHub 原生渲染。
- **喂给 Agent / RAG**：
  - 语义检索场景 → 优先使用 `Agent基础库 Q&A.json`（每条含 `module` / `subsection` / `question` / `answer` 字段）。
  - 整库上下文注入 → 可将三个 `.md` 拼接后作为系统提示（system prompt）的附件。
- **多语言**：中文问答库面向中文面试官；英文简历供海外/英文场景参考。

## 内容说明

- 问答库以候选人第一人称撰写，基于简历事实 + 候选人自述整理。
- 标注 `⚠️` 的条目为 AI 基于简历补充的草稿，正式使用前请候选人确认/替换。
- 简历与问答库中的公司、日期、数据均以简历原文为准。
